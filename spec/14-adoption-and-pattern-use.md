# Adoption and pattern use

## Start from a verifiable source

The getting-started guide uses the repository workflow: clone the source, install
with the checked-in lockfile, build the workspace, and start the showcase. It does
not assume that the workspace package names are available in a public registry.
The declared toolchain is Node.js 20+ and pnpm 10.15.0.

The React starter imports both token and component styles. It uses an explicit
language and a local ThemeProvider direction without changing document settings.
The example performs local validation and clearly states that no data was saved.
Another app must configure the workspace dependencies and font loading; copying a
snippet alone is not a complete installation or persistence integration.

Religious connection: [Al-Isra 17:36](https://quran.com/al-isra/36) motivates
verified claims; [Bukhari 69](https://sunnah.com/bukhari:69) motivates an easy first
step; [An-Nisa 4:58](https://quran.com/an-nisa/58) motivates careful handling of
work; [Al-Ahzab 33:70](https://quran.com/al-ahzab/70) motivates truthful feedback.
These are ethical applications, not scripturally prescribed setup commands.

## Pattern tiers

| Tier | Use | Specimen mapping |
| --- | --- | --- |
| None | Forms, reading, dense data, and ordinary workspaces | No generated pattern |
| Quiet | Subtle section edge or restrained empty-state accent | Quiet jali in a small decorative band |
| Supporting | Section boundary or chapter introduction | Balanced jali in a bounded band |
| Expressive | Cover, introduction, or deliberate brand moment | Balanced rosette in a larger bounded band |

These are editorial usage tiers, not new `PatternSurface.intensity` API values.
The API continues to use `quiet` and `balanced`. The specimen keeps all reading
and functional content on a separate solid plane. Switching tiers preserves that
content and its hierarchy. Decoration is off by default and hidden from assistive
technology. High contrast removes the specimen ornament without removing content.

Religious connections: [Bukhari 1](https://sunnah.com/bukhari:1) informs purposeful
intention, [Muslim 91a](https://sunnah.com/muslim:91a) informs beauty with respect
for people, and [Al-Isra 17:70](https://quran.com/al-isra/70) informs dignity and
access. These do not prescribe a geometric ratio, pattern family, or ornament
percentage. Sacred text MUST remain explanatory content, never decorative texture.

## Validation

Browser scenarios cover repository instructions, field repair and retained input,
truthful local validation, Arabic example generation, manual-copy fallback,
pattern switching, decorative semantics, high-contrast ornament removal, and
narrow Arabic layouts. Copy failure does not hide the source or claim success.
Broader accessibility, language, and real-product adoption reviews remain pending.
